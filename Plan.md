Learn Go by going back through your own code.
Open your proof of concept and explain it line by line. 
Where did you pass a pointer instead of a value? 
Where did you use an interface? 
How did you handle errors? 
Learning the four topics against code you wrote is quicker than studying them abstractly. 
Give each topic about an hour, and stop there unless you're applying for Go roles.
