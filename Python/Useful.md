`print()`


`\n` newline

`phrase = 'hello \n world`
```
hello
 world
```


`\"` double quotes and `\'` single quote
``` python
string = "she said \"lol\""
print(string)
>> 'she said "lol"'
```
but also can just do alternating which saves the use e.g.
``` python 
string = 'she said "lol"'
print(string)
>> 'she said "lol"'
```

`\t` tab
```
hello      world
```

`\\` backslash
``` python
string = "hello\\loser.com"
print(string)
>> "hello\loser.com"
```

`"""` `'''` multi-line string 
``` python
address = """ 
Scarle
Ellingham Road
HP2 5LE 
"Thats my address"
No it's not
"""

print(address)

Scarle
Ellingham Road
HP2 5LE 
"Thats my address"
```
