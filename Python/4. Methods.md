#### HOW TO FIND METHODS 

In command line can use

``` python
dir(first_name)                 # lists all the methods
help(first_name.capitalize)     # explains one method
```


### Method Params in the Docs

``` python
str.upper() # no params
str.strip([chars]) # [] = optional, if empty it removes trailing white space

```


``` python
test = "star.phillips   "
call_it = test.strip().upper()
print(call_it)

# STAR.PHILLIPS

```
