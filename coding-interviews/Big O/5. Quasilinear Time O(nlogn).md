Most built-in sorting functions are nlogn

Example:
- quicksort
- mergesort
- heapsort

``` python
import heapq
nums = [1, 2, 3, 4, 5]
heapq.heapify(nums)    #O(n) - we know the complexity of heap building
while nums:
	heapq.heappop(nums) # O(logn)
```
Thus, when we do O(n) x O(logn) we are doing log, n times. Therefore **O(nlogn)**
