
O(log n) means each step throws away half of what's left.

Doubling up to n and halving down from n are both O(log n)

Ask: how many times can you cut the value by 2 until it equals 1

Example:
- Binary search
- Heap push and pop



Pseudo Example:
```
Guess a number between 1 and 100
> 50
Go higher
You are cutting off half the results for your next guess
```

Code Example:
``` python
def search(root, target):
	if not root:              # 50% cut as you now only search target
		return False
	if target < root.val:     # 50% cut as now searching one half
		return search(root.left, target)
	elif target > root.val:   # if condition its the other half
		return search(root.right, target)
	else:
		return True           # if condition it is root
```
