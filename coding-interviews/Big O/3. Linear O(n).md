What is O(n) - As our input grows, our time will also grow

Array: sum (we will go through every number in the array and add together) so here we can about the input and since its more than 1 its n

``` python
nums = [1, 2, 3] 
sum(nums)                      # sum of array
	for n in nums:             # looping (exactly what sum does)
	print(n)
```

``` python
nums.insert(1, 100)          # insert middle
nums.remove(100)             # remove middle
print(100 in nums)           # search
```

Above is O(n) as you don't know how much you'll have to move to get to the desired position

``` python
import heapq
heapq.heapify(nums)         # build heap
```
