**9. `mystery2`: you said O(2ⁿ), it's O(n log n).** The outer loop runs n times. The inner loop uses `j *= 2`, so j goes 1, 2, 4, 8, ... and reaches n after only log n steps. It's the same halving idea as #3, just running in the opposite direction. So it's n × log n.

**10. `isPrime`: you said O(n!), it's O(√n).** The loop stops when `i * i > n`, which means `i` only goes up to the square root of n. Nothing here multiplies choices together, so factorial is way off.




**A trick for loops:** ask how the loop variable changes each step, and when it stops.

- Goes up by 1 until n: O(n).
- Doubles or halves each time: O(log n).
- Stops at `i * i <= n`: O(√n).
- A loop inside a loop multiplies the two.
